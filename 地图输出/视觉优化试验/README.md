# 视觉优化试验

这些文件是视觉方案对比稿。原来的正式地图没有被覆盖或删除。

## 全国图

`全国_层级强调版/铁路路线.png`：保留全国底图和原有绿色/青绿色路线体系，增加路线与行政边界的明度和宽度差异，放大车站和重点城市标签。这个版本暂时不放局部放大框。

`全国_层级强调版/去过的省市.png`：保留省级和地级行政区层级，增强去过城市的连续色块和城市标签。这个版本暂时不放局部放大框。

## 区域图

`东北漫游/东北漫游_强调版.png`：用于检查长距离、跨省路线的主次层级。路线更醒目，车站点和标签略放大，市界保持在省界以下。

`小城小记3/小城小记3_强调版.png`：用于检查短距离、多站点路线。路线、站点和重点县区同时存在时，重点仍然落在实际行程上。

区域图旁边的 `.qgz` 是对应的可编辑试验项目；PNG 是本次比较的主要结果。

## 第二版：路线主角

`第二版_路线主角/全国/铁路路线.png` 和 `第二版_路线主角/全国/去过的省市.png` 是重新制作的全国图。路线使用明显的外描边和更宽的主线，铁路图减少低频车站标签，足迹图提高到访省份的色阶。

`第二版_路线主角/东北漫游/东北漫游_强调版.png` 和 `第二版_路线主角/小城小记3/小城小记3_强调版.png` 增加行程顺序节点：起点和终点使用红色大节点，中途站使用青绿色节点。节点上的数字对应路线顺序。

## 第三版：底图与标签分级

`第三版_底图分级/全国/铁路路线.png`、`第三版_底图分级/东北漫游/东北漫游_底图分级.png` 和 `第三版_底图分级/小城小记3/小城小记3_底图分级.png` 使用低对比度地形、主要河流和主要湖泊作为背景。地形保持低透明度，水系使用浅蓝色，路线仍然位于最上层。

第三版同时调整了标签等级：核心城市使用较大深色字，普通到访城市使用较小灰青色字，车站只保留乘车次数较多的标签，县区名称和省级名称使用不同字号。

底图数据来自 Natural Earth 的 Gray Earth、Lakes 和 Rivers + lake centerlines 数据集。原正式地图没有使用这些新增图层。
