# 涞源县旅游图制作说明

## 成果

- `涞源县旅游图.png`：竖版成图，页面为 112.395 × 150.707 mm，导出分辨率为 120 dpi（531 × 712 px），与参考图比例一致。
- `涞源县旅游图.qgz`：可继续编辑的 QGIS 工程，使用相对路径引用同目录数据。
- `涞源县旅游图_数据.gpkg`：工程所需的县区、景点、道路、河流和地名图层。
- `构建报告.json`、`校验报告.json`：自动构建及工程完整性检查结果。

## 复刻思路

版面按照参考图的主要视觉结构重建：顶部黑色刊头、叠在底图上的大标题、浅色周边县区、绿色涞源县轮廓、县域外缘阴影、虚线景点引线、分类色块和左下角图例。页面比例为 531:712，地图范围固定为 `114.24,38.99,115.16,39.92`。所有结构均由 QGIS 图层或布局元素绘制，没有把参考图作为背景贴图，因此文字、线条、色块、景点位置及层级均可单独编辑。

大标题使用本机可稳定调用的黑体，景点正文、说明和刊头使用微软雅黑。大标题“北京周边”采用黄色填充与黑色描边，以接近参考图的醒目层次。脚本没有使用未安装的字体名称，避免 QGIS 静默回退为宋体。

## 数据与图层

行政区边界来自仓库 `city/baoding.geojson`，并在文件存在时补入 `city/zhangjiakou.geojson` 和 `city/datong.geojson` 的邻接县区。涞源县边界只取同一份县级数据，避免县界与周边边界来自不同精度的数据源。

GeoPackage 内含以下图层：

- `context_admin`：地图范围内的周边县区。
- `laiyuan_county`：涞源县本体。
- `laiyuan_glow`：由涞源县边界依次缓冲得到的三层轮廓光。
- `roads`：用于复刻版式的国道、高速和旅游道路骨架。
- `rivers`：拒马河、唐河示意线。
- `tourism_pois`：24 个景点锚点，包含名称、类别、标签、说明和卡片布局参数。
- `context_labels`：蔚县、灵丘、易县等周边地名。

道路、河流及景点位置用于旅游信息图表达，属于手工制图锚点，不应直接用于导航。后续获得更精确的道路或 POI 数据时，可替换对应图层并保留现有布局。

## 编辑方法

在 QGIS 中打开 `涞源县旅游图.qgz`，进入布局管理器并打开“涞源县旅游图”。景点名称、分类块、说明和虚线引线都是独立布局项，可以直接移动；景点实际锚点在 `tourism_pois` 图层中，可开启编辑后调整位置。

脚本中的 `POIS` 同时保存了可重复构建时使用的景点坐标及布局参数。若需要长期保留在 QGIS 中手动调整后的结果，应另存工程；再次运行构建脚本会重新生成专题 GeoPackage 和布局。

