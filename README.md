### 区域线路图

现行区域图位于 [`地图输出/区域线路图`](地图输出/区域线路图)，包括甘肃行旅、走河西、山陕漫游、回家路上、小城小记等系列。

每组成果通常包含：

- `.png`：可直接查看和用于网页发布的成图。
- `.qgz`：QGIS 工程。
- `.gpkg`：工程对应的自包含矢量图层数据。

当前发布工程和配套数据均低于 GitHub 的单文件大小限制，因此随成图一并发布。仓库不包含历史版本、构建与校验报告、OSM 缓存、未使用的网页导出数据和博客源文件。

## 目录说明

- [`地图输出/全国专题图`](地图输出/全国专题图)：全国足迹、铁路路线、铁路枢纽局部图、航线图等现行成果。
- [`地图输出/区域线路图`](地图输出/区域线路图)：当前统一风格的各篇区域路线图。
- [`地图输出/旅游专题图`](地图输出/旅游专题图)：县域旅游信息图、QGIS 工程及自包含专题数据。
- [`制图工具/scripts`](制图工具/scripts)：QGIS Python 构建与校验脚本。
- [`制图工具/数据源/GeoPackage/route_sources.gpkg`](制图工具/数据源/GeoPackage/route_sources.gpkg)：全国参考铁路及两套专题路线源图层。
- [`制图工具/symbology-style.db`](制图工具/symbology-style.db)：QGIS 样式库。
- [`city`](city) 与 [`province`](province)：市、县区和省级行政区边界。
- [`QGIS旅行铁路地图制图流程.md`](QGIS旅行铁路地图制图流程.md)：现行视觉规范、数据口径和制图流程。

基础矢量数据统一使用 GeoPackage，不再保留 Shapefile。`route_sources.gpkg` 包含 `railway`、`trip_route_home3` 和 `trip_route_ss` 三个图层：前两者分别作为全国铁路参考层和回家路上 3 原始路线备份，`trip_route_ss` 由山陕漫游脚本直接读取。多数发布工程已把所需图层写入同目录的专题 `.gpkg`，其他脚本则直接读取 `city`、`province` 或全国足迹输出数据。

## 本地数据

`制图工具/数据源/GeoPackage/travel_map_home2_min_gan.gpkg` 约 213 MB，包含全国铁路 OSM 线与点，是 `travel_history/build_routes.py`、`travel_history/inspect_sources.py` 和计划行程选路脚本的原始数据源。它超过 GitHub 普通仓库的单文件限制，只在本机保留并由 `.gitignore` 排除；运行这些脚本前需要确保该文件存在。

`k158_planned` 保存按中国铁路 12306 的 `2026-08-23` 时刻表绘制 K158 专题图所需的数据和脚本。K158 同时作为第 `133` 段普铁记录写入全国足迹，采用 `2725 km` 的统计里程；中间经停站仅用于约束路线，不增加全国图的到发车站数量。

早期的 `travel_map.gpkg` 没有现行脚本引用，已删除。已发布地图目录中的专题 `.gpkg` 是体积较小、可继续编辑的工程数据，仍纳入仓库。
