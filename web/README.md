# 中国铁路图网页

这是全国铁路图的交互版。网页默认显示铁路行程和铁路到达城市；左侧图层开关可以组合显示全国铁路底图、高铁/动车行程、普速铁路行程，以及按设计速度（缺少设计速度时使用 `maxspeed`）着色的全国铁路网络。主地图直接包含完整中国范围和南海诸岛，不再使用右下角插图。城市名称在缩放到 5 级后显示，车站名称在缩放到 7 级后显示；选择单一铁路类型时，车站也会同步筛选。其他到访城市使用浅色单独显示。

由于浏览器限制，网页需要通过本地静态服务器打开。在仓库根目录执行：

```powershell
python -m http.server 4178 --bind 127.0.0.1 --directory web
```

然后打开 <http://127.0.0.1:4178/>。也可以使用任意静态网站托管服务发布整个 `web` 文件夹。

`制图工具/scripts/railway_web/build_web_data.py` 用于从本地 QGIS 数据源重新导出网页数据。

当前数据包含 137 段铁路行程、132 个行程车站、68 个铁路到达城市，以及经过客运站筛选的 5,518 个全国车站点。全国铁路网和全国车站仅在首次启用全国路网时加载；全国车站只在缩放到 9 级后出现，名称在 12 级后出现，以避免首屏和全国视图卡顿。

在 Blog 父仓库执行 Hexo 生成时，`scripts/map_publish.js` 会把本页复制到博客的 `/map/` 路径，并按内容生成资源版本号。

`/map/hubs/` 是铁路枢纽图子页，提供北京、合肥、广州三个局部视图。它直接复用 `/map/data/` 中的铁路行程、车站和行政区数据，可切换枢纽、显示线路类型、地级市边界、重点车站和城市名称；主网页顶部的“铁路枢纽图”按钮可以进入该页面。Hexo 发布时会连同 `web/hubs/` 目录一起复制到 `/map/hubs/`。

左侧“路线附表”可以搜索并勾选路线；勾选多条时会叠加显示，清空选择后地图只保留边界和底图。路线鼠标悬停时会显示车次、起终点和里程。
路线附表的选择还会联动城市高亮：地图只高亮当前所选路线的起点和终点城市。
