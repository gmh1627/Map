# 中国铁路图网页

这是全国铁路图的交互版。网页默认显示到过的铁路路线和铁路到达城市；左侧图层开关可以组合显示全国铁路底图、到过的高铁/动车、到过的普速铁路，以及按设计速度（缺少设计速度时使用 `maxspeed`）着色的全国铁路网络。城市名称在缩放到 5 级后显示，车站名称在缩放到 7 级后显示；选择单一铁路类型时，车站也会同步筛选。其他到访城市使用浅色单独显示。

由于浏览器限制，网页需要通过本地静态服务器打开。在仓库根目录执行：

```powershell
python -m http.server 4178 --bind 127.0.0.1 --directory web
```

然后打开 <http://127.0.0.1:4178/>。也可以使用任意静态网站托管服务发布整个 `web` 文件夹。

`制图工具/scripts/railway_web/build_web_data.py` 用于从本地 QGIS 数据源重新导出网页数据。

当前数据包含 135 段到过路线、131 个到过车站、68 个铁路到达城市，以及经过客运站筛选的 5,518 个全国车站点。全国车站只在缩放到 9 级后出现，名称在 12 级后出现，以避免全国视图卡顿。

左侧“路线附表”可以搜索并勾选路线；勾选多条时会叠加显示，清空选择后地图只保留边界和底图。路线鼠标悬停时会显示车次、起终点和里程。
路线附表的选择还会联动城市高亮：地图只高亮当前所选路线的起点和终点城市。
