# 中国铁路图网页

这是全国铁路图的交互版。网页默认显示铁路行程和铁路到达城市；左侧图层开关可以组合显示全国铁路底图、高铁/动车行程、普速铁路行程，以及按设计速度（缺少设计速度时使用 `maxspeed`）着色的全国铁路网络。主地图直接包含完整中国范围和南海诸岛，不再使用右下角插图。城市名称在缩放到 5 级后显示，车站名称在缩放到 7 级后显示；选择单一铁路类型时，车站也会同步筛选。其他到访城市使用浅色单独显示。

由于浏览器限制，网页需要通过本地静态服务器打开。在仓库根目录执行：

```powershell
python -m http.server 4178 --bind 127.0.0.1 --directory web
```

然后打开 <http://127.0.0.1:4178/>。也可以使用任意静态网站托管服务发布整个 `web` 文件夹。

`制图工具/scripts/railway_web/build_web_data.py` 用于从本地 QGIS 数据源重新导出网页数据。

完整铁路行程以 `制图工具/scripts/travel_history/railway_records.csv` 为校对来源，日期、起终点、车次、里程和时刻保存在同一行。修改后依次运行 `travel_history/parse_source.py`、`travel_history/sync_rail_records.py`、`railway_web/build_web_data.py`；同步脚本会更新工程中的记录属性和 `web/data/route_times.json`，导出时再核对起终点、车次，避免拆分或合并行程后时刻错位。

右上角“返回主页”可返回博客主页 <https://kangaroogao.com/>。

网页行政边界与静态专题图采用同一套边界处理规则：省界来自统一溶解后的省级几何，市界只保留同省城市之间的内部共享边，并将内部边端点吸附到统一省界。城市外轮廓不再重复叠加，因此省界和市界在交界处只显示一条连续边线。

当前数据截至 2026 年 11 月，包含 148 段铁路行程（普铁 53 次、高铁/动车 95 次），总里程 62,666 km（普铁 27,514 km、高铁/动车 35,152 km），涉及 144 个行程车站、76 个铁路到达城市，以及经过客运站筛选的 5,518 个全国车站点。铁路到达城市按行程起终点所属地级行政区去重，包含兴安盟和大兴安岭地区，界面统一写作“76 个城市”；静态铁路图采用同一统计口径。其他到访城市包含南宁。完整的已乘坐路线随首屏数据一起加载；19 MB 的全国铁路详细网络不阻塞首屏，而是在首次启用全国路网时加载 1.5 MB 的概览数据。全国车站只在缩放到 9 级后出现，名称在 12 级后出现。网页数据使用浏览器缓存，版本号更新后才重新请求。

左侧“行程年份”支持同时选择多个年份，再次点击已选年份可取消，取消最后一个年份或点击“全部年份”时恢复全部年份。地图轨迹、路线附表、城市高亮、站点和统计同步显示所选年份的记录；多个年份的城市和车站合并去重，里程采用行程表中的记录里程。

“线路范围”的北京、合肥、广州按钮会切换到对应城市及周边视图，筛选起点或终点位于该范围内的行程；“全部”恢复全国范围。范围与年份、铁路类型、行程勾选共同筛选，统计随当前显示的行程更新。“重置视图”回到当前所选范围。

在 Blog 父仓库执行 Hexo 生成时，`scripts/map_publish.js` 会把本页复制到博客的 `/map/` 路径，并按内容生成资源版本号。

`/map/hubs/` 是铁路枢纽图子页，提供北京、合肥、广州三个局部视图。它直接复用 `/map/data/` 中的铁路行程、车站和行政区数据，可切换枢纽、显示线路类型、地级市边界、重点车站和城市名称；主网页顶部的“铁路枢纽图”按钮可以进入该页面。Hexo 发布时会连同 `web/hubs/` 目录一起复制到 `/map/hubs/`。

左侧“路线附表”可以搜索并勾选路线；勾选“高铁 / 动车行程”或“普速铁路行程”后，地图和附表会同步只保留对应类型，两个选项同时勾选时显示两类。勾选多条时会叠加显示，清空选择后地图只保留边界和底图。路线鼠标悬停时会显示车次、起终点和里程。
路线附表的选择还会联动城市高亮：地图只高亮当前所选路线的起点和终点城市。
